# 🤖 DocPilot AI

An AI-powered document assistant built using the MERN Stack.

## 🚀 Features
- User Registration & Login
- JWT Authentication
- Protected Routes
- Subscription Plans
- Responsive Dashboard
- REST API Integration

## 🛠️ Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- JWT
- Bootstrap
- Axios
